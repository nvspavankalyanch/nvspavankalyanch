## 🚀 About Me

Backend & AI Engineer with 2.5 years of production experience. Built and owned the Python backend of a multi-tenant EdTech SaaS platform serving 5,000+ daily users across 50 institutes, and took its AI platform from v0.1 to a production multi-agent system with RAG, tool calling, and streaming responses.

- ⚙️ Backend core: Python, FastAPI, PostgreSQL, SQLAlchemy, Redis, Celery, microservices
- 🤖 AI in production: RAG pipelines, multi-agent systems, tool calling, and multi-LLM integration
- 🛡️ Reliability: transactional outbox, idempotency, rate limiting, structured logging
- 🔭 Currently building: **Termix** — a terminal-based HTTP client written in Python
- 📖 Currently learning: Go, System Design
- 📜 Certified: AI Capabilities and Limitations (Anthropic) · Claude 101 (Anthropic) · Introduction to LangChain – Python
- 🎓 B.Tech in Electronics and Communication Engineering, KLEF (2016–2020)
- 📍 Hyderabad, India · Immediate joiner
